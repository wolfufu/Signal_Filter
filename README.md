## 📡 Signal Filter

REST API-сервис для генерации зашумлённого синусоидального сигнала и определения его доминирующей частоты с помощью быстрого преобразования Фурье (БПФ).

Проект контейнеризирован с помощью Docker и может быть легко развёрнут в любой среде.

## 🚀 Возможности

- ✅ **Генерация сигнала** – создание синусоидального сигнала с заданной частотой и добавление реалистичного экспоненциально-коррелированного шума.
- ✅ **Частотный анализ** – определение доминирующей частоты с помощью БПФ (отфильтрованной спектральной плотности мощности).
- ✅ **REST API** – удобный эндпоинт для получения частоты через HTTP-запрос.
- ✅ **Параллелизация** – использование Numba для ускорения генерации временной сетки (параллельные циклы).
- ✅ **Docker-образ** – простота развёртывания и воспроизводимость окружения.
- ✅ **Интерактивная документация** – автоматически генерируемый Swagger UI (по адресу `/docs`).

## ⚡ Быстрый старт

### Предварительные требования

- Python 3.13+
- pip (менеджер пакетов)
- (Опционально) Docker

### Установка и запуск (локально)

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/wolfufu/Signal_Filter.git
cd Signal_Filter
```

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Запустите сервер:**
```bash
uvicorn app.main:app --reload
```

Сервер запустится на `http://127.0.0.1:8000`.

### Запуск через Docker

1. **Соберите образ:**
```bash
docker build -t signal_filter .
```

или подтяните готовый образ с Docker Hub:
```bash
docker pull wolfufu/signal_filter:latest
```

2. **Запустите контейнер:**
```bash
docker run -d --name signal_filter_container -p 8000:8000 signal_filter
docker run --name signal_filter_container -p 8000:8000 wolfufu/signal_filter:latest      
```

После этого API будет доступен по адресу `http://localhost:8000`.

## 🛠️ Использование

### Пример запроса (curl)

```bash
curl "http://localhost:8000/detect_frequencies?freq=30"
```

```json
  "detected_frequency_hz": 30.0,
  "sampling_rate_hz": 1000.0,
  "signal_lenght_samples": 100000

```

### Пример запроса (Python requests)

```python
import requests

response = requests.get("http://localhost:8000/detect_frequencies", params={"freq": 30})
data = response.json()
print(data)
```

## 📡 API эндпоинты

| Метод | Эндпоинт                 | Параметры                                  | Описание                                                                 |
|-------|--------------------------|--------------------------------------------|--------------------------------------------------------------------------|
| GET   | `/detect_frequencies`    | `freq` (float) – частота запрашиваемого сигнала в Гц (0 < freq ≤ 500) | Генерирует зашумленный сигнал с заданной частотой и возвращает обнаруженную доминирующую частоту. |

### Валидация параметров

- Если `freq < 0.0`, API возвращает ошибку `400` с сообщением: `"Frequency must be greater than or equal to 0"`.
- Если `freq > 500.0`, API возвращает ошибку `400` с сообщением: `"Frequency must be less than or equal to 500"`.

### Интерактивная документация

- ReDoc: `http://localhost:8000/redoc`

## 🏗️ Структура проекта

```
Signal_Filter/
├── app/                     # Основная директория с исходным кодом
│   ├── main.py              # FastAPI приложение (эндпоинты)
│   └── sim_signal.py        # Модуль генерации сигнала и частотного анализа
├── Dockerfile               # Инструкции для сборки Docker-образа
├── requirements.txt         # Зависимости Python
└── .gitignore               # Исключения для Git
```

### Краткое описание файлов

- **`main.py`** – входная точка приложения. Содержит настройку FastAPI, эндпоинт `/detect_frequencies` и базовую валидацию входящих параметров.
- **`sim_signal.py`** – модуль с бизнес-логикой:
  - `parallel_arange` – параллельная генерация временной сетки (использует Numba).
  - `create_signal` – создание синусоидального сигнала с добавлением шума.
  - `find_freq` – определение доминирующей частоты через БПФ.
  - `draw_grafs` – визуализация сигнала и спектров (опционально).

## 🐳 Контейнеризация

### Сборка Docker-образа

```bash
docker build -t signal_filter .
```

- Флаг `-t signal_filter` задаёт имя образа (должно быть в нижнем регистре).
- Точка (`.`) указывает контекст сборки — текущая директория.

### Запуск контейнера

```bash
docker run -d --name signal_filter_container -p 8000:8000 signal_filter
```

- `-d` – запуск в фоновом режиме (detached mode).
- `--name signal_filter_container` – задаёт имя контейнера.
- `-p 8000:8000` – пробрасывает порт 8000 контейнера на порт 8000 хоста.

### Остановка и удаление контейнера

```bash
docker stop signal_filter_container
docker rm signal_filter_container
```

## 💡 Примечания

- Частота дискретизации в модуле `sim_signal.py` установлена на `1000 Гц` (`dt = 0.001`), поэтому максимальная частота, которую можно корректно детектировать, составляет `500 Гц` (частота Найквиста). Поэтому в API установлено ограничение `freq ≤ 500`.
- Для визуализации сигнала вы можете использовать функцию `draw_grafs` из `sim_signal.py`.
